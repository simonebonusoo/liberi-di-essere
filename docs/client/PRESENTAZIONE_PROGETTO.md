# Presentazione Progetto

Liberi di Essere e una demo gestionale pensata per semplificare prenotazioni, organizzazione staff e gestione appuntamenti di un salone femminile.

## Valore

- Prenotazione online guidata.
- Area cliente semplice.
- Calendario admin operativo.
- Dati demo modificabili.
- Base pronta per Supabase e deploy.
