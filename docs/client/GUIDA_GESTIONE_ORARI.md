# Guida Gestione Orari

## Disponibilita

Da admin si gestiscono fasce staff per sede e giorno. Le fasce non possono sovrapporsi.

## Demo week

La funzione di copia settimana demo replica le fasce del martedi sui giorni successivi, evitando duplicati.

## Chiusure

Le chiusure possono essere globali o legate a una sede.
