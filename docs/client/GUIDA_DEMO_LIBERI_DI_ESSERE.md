# Guida Demo Liberi di Essere

Questa demo mostra sito, prenotazione online, area cliente e pannello admin del gestionale Liberi di Essere.

## Accesso

Usare i pulsanti demo nella pagina login:

- Cliente demo.
- Amministratore demo.
- Super admin demo.

## Cosa provare

- Visitare servizi e sedi.
- Creare una prenotazione.
- Aprire le notifiche.
- Consultare calendario e disponibilita da admin.
